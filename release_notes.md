First release of Stremio for Android Automotive OS (AAOS), adapted from official mobile v2.5.0 (`com.stremio.one`). 

Designed and tested on the 15.4" Polestar 4 display (1920x1200), but may work on other vehicles running AAOS.

### Key changes
- Clean 6-poster shelves across Home, Discover, and Search with readable ratings and zero edge clipping
- 6-column Discover grid instead of 7 cramped columns, with ~6x larger poster area
- Wider 140dp sidebar with 42dp icons and 18sp text you can tap from the seat
- Video player controls stay on screen while parked, with a thick seekbar, 24sp timestamps, and dedicated +/-10s skip buttons
- 5 large bottom player action buttons (Subtitles, Audio, Speed, Video Scaling, Player)
- Fixed video scaling toggle (Fit, Crop, Stretch, Original); removed phone screen-rotation button
- Full-width settings layout (1,195px) replacing the cramped 210px mobile strip
- Clean 4K / Instant Play stream cards with audio format badges (Dolby Vision, Atmos)

### Install
1. Download directly on the car using the built-in browser (or copy over with a USB drive or phone).
2. Open the file and allow installation from unknown sources when prompted.

*For use while parked only (e.g. charging stops).*
